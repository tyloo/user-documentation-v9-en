## PrestaShop 9 Hummingbird Theme

PrestaShop 9 introduces **Hummingbird**, a brand-new front office theme that represents the next generation of PrestaShop themes.

### Key Features
- **Bootstrap 5 LTS**: Built with the latest Bootstrap framework for modern, consistent design
- **TypeScript**: Enhanced JavaScript development with TypeScript
- **BEM CSS Architecture**: Clean, maintainable CSS using BEM naming convention
- **Performance Optimized**: Faster loading times and better user experience
- **Mobile First**: Responsive design optimized for all devices
- **Dark Mode Support**: Built-in support for dark mode themes
- **Modern Standards**: Follows current web development best practices

### Benefits
- **Better Performance**: Optimized code structure and modern build tools
- **Easier Customization**: Cleaner architecture makes theme modifications simpler
- **Future Proof**: Built on modern technologies for long-term maintainability
- **Developer Friendly**: Better tools and structure for developers

### Availability
While Hummingbird is not the default theme in PrestaShop 9, it sets the direction for the future of PrestaShop theming. It's available for testing and development purposes.

{% hint style="info" %}
Hummingbird is designed to be a foundation for future PrestaShop themes and provides a modern alternative to the Classic theme.
{% endhint %}

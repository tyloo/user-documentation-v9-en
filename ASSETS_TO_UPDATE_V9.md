## Notes for Asset Updates

### V9-Specific Changes to Capture:
1. **New Product Page**: Now default interface with Symfony migration
2. **Admin API**: New API documentation interface at `/api/docs`
3. **Hummingbird Theme**: New theme interface and customization options
4. **Bootstrap 5**: Updated UI components and styling
5. **Enhanced Navigation**: Improved back office navigation
6. **Better Mobile Experience**: Responsive design improvements
7. **Dark Mode**: Theme switching capabilities
8. **Improved Forms**: Better form validation and user experience

### Asset Naming Convention:
- Use descriptive names instead of generic "image (X).png"
- Include version information: `prestashop-9-` prefix
- Include feature context: `product-page-`, `admin-api-`, `hummingbird-`
- Include action context: `-interface`, `-creation`, `-management`

### Recommended Asset Sizes:
- **Interface Screenshots**: 1920x1080 or 1440x900
- **Modal Dialogs**: 800x600
- **Mobile Screenshots**: 375x667 (iPhone) or 360x640 (Android)
- **Icon Screenshots**: 64x64 or 128x128

### File Organization:
- Create subdirectories by feature: `admin-api/`, `hummingbird/`, `product-page/`
- Use consistent naming: `prestashop-9-[feature]-[action].png`
- Include both light and dark mode versions where applicable
